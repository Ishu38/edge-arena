## 🧐 Why Edge Arena?

Running AI locally is confusing.
- *"Will Llama-3 run on my 16GB MacBook?"*
- *"Can I use Phi-3 for a commercial startup?"*
- *"What is the exact Ollama command to run Mistral?"*

**Edge Arena** answers these questions in seconds. It is a clean, noise-free dashboard designed for developers who want to **run** models, not just read research papers.

## ✨ Features

- **🚀 One-Click Run:** Instantly copy the `ollama run` command for any model.
- **⚖️ License Filter:** Toggle between "All", "Apache 2.0" (Commercial), and "Research Only" models.
- **📊 Visual Benchmarks:** See MMLU and HellaSwag scores at a glance.
- **🏷️ Hardware Tags:** Know immediately if a model is for "IoT", "Mobile", or "Edge".
- **⚡ Zero-Latency:** Built on Next.js for instant page loads.

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Icons:** Lucide React
